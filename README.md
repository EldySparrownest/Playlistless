# Playlistless

Playlistless is a browser extension for Firefox with 3 simple features usable on YouTube videos originating from playlists:
- open video without playlist in the current tab
- open video without playlist in a new tab
- copy a pure link to the video (without the playlist or any other parameters)

It is not available in Mozilla add-ons _yet_.

## Languages

- **English** - the default language
- **Czech** - currently the only other available language (used if browser language is set to Czech)
